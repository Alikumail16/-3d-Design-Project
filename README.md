# 3D Gear Design Project

## Overview
This project demonstrates the design and 3D modeling of a spur gear using CAD software.

## Features
- Accurate gear calculations
- 3D CAD model
- Standard involute tooth profile
- Manufacturing-ready design

## Software Used
- AutoCAD

## Applications
- Mechanical systems
- Gear assemblies
- Educational projects
